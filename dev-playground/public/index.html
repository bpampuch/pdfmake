How it works & keyboard shortcuts
Define var dd = { content: [...] };. Use Ctrl/⌘ + Enter to run, Tab to indent, and Ctrl + Space for completions. The engine runs in a disposable worker so Cancel and the time limit can stop a blocked render. PDF.js renders the preview directly, including page navigation, zoom and extracted page text. Open PDF and Download PDF are also available.
Run only JavaScript you trust. Custom code executes in your browser and is not a security sandbox. Live preview updates imports and restored documents automatically when enabled. Turn it off before importing code you want to inspect first. Your current workspace, selection and undo history are autosaved in this browser. Named documents and quick drafts are separate local saves. Clear workspace autosave removes the last workspace until you type again. No code or PDF is uploaded by this playground. URL resources are disabled in the PDF API; use embedded images and bundled fonts.
